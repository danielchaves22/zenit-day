# Documentação do Zenit Day

## Uso e operação

- [Primeiro uso](PRIMEIRO_USO.md): instalação, conceitos, sincronização e cópias.
- [Lembretes](LEMBRETES.md): recorrência, persistência, autorização e entrega pelo Hub.
- [Preparação do Supabase](SUPABASE_PASSO_A_PASSO.md): configuração do ambiente e verificações.
- [Contrato Supabase](SUPABASE_CONTRATO.md): armazenamento e sincronização.
- [Integração Hub](ZENIT_HUB.md): OAuth, RLS, consentimento e páginas web de autorização.

O Day é a fonte das regras de lembrete. O Hub guarda assinaturas e entrega; conectar Day não ativa mensagens automaticamente. Os guias públicos ficam no [portal Zenit](https://zenitapp.net/docs/help/zenit-day/getting-started/), e a operação do canal está na [documentação do Hub](https://github.com/danielchaves22/zenit-hub/tree/master/docs).
